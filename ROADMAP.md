# Model Modding Roadmap

This roadmap prioritises proving the standard before expanding the ecosystem.

## v0.1 — Foundation

- Define the anatomy of a mod
- Publish `mod.yaml` and recipe schemas
- Create reusable mod and evaluation templates
- Add reference mods and one composed recipe
- Validate repository content automatically
- Establish contribution, governance and security guidance

## v0.2 — Working toolkit

- Release a CLI for creating, inspecting and validating mods
- Add composition, dependency and conflict rules
- Publish model-provider compatibility guidance
- Add regression evaluation support

## v0.3 — Community workshop

- Launch Requests for Mods
- Publish no-code contributor pathways
- Create domain and evaluation working groups
- Run the first community modding challenge
- Publish transparent maturity criteria

## v0.4 — Registry and playground

- Launch a searchable mod registry
- Build a visual playground for composing recipes
- Show compatibility, evaluation evidence and remix lineage
- Support third-party mod repositories

## v1.0 — Open ecosystem standard

- Stabilise the manifest specification
- Provide migration and versioning guarantees
- Establish independent maintainership
- Publish governance and release processes suitable for wider adoption

## Current priority

The immediate goal is a small end-to-end demonstration: define a mod, validate it, compose it into a recipe and evaluate the resulting behaviour.
