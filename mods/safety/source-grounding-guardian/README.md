# Source Grounding Guardian

Source Grounding Guardian is a narrow assurance mod for keeping transformed output tied to the material actually supplied.

## Purpose

It protects source-supported claims and uncertainty. It prevents invented claims, fabricated citations, presentation of missing evidence as supplied evidence, and advice that is not grounded in the source or package contract.

## Use it when

- the source is incomplete or ambiguous;
- the output must distinguish source statements from interpretation;
- citations, quotations, studies or official details could be invented;
- unsupported advice could alter action in a high-stakes context.

## Limitations

This mod supplies behavioural instructions and declared invariants. It cannot verify external facts without an actual retrieval or citation mechanism, and the current evaluator does not yet perform full semantic source-output comparison.

It does not own deadlines, obligations or exceptions except when the source does not contain the claimed detail.
