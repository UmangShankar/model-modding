# Benchmark Evidence

This directory contains reproducible, reviewable benchmark evidence generated by Model Modding.

Published results must come from an actual benchmark run. Do not add illustrative, estimated or hand-authored scores as evidence.

## Required package

Each published benchmark lives at:

```text
evidence/benchmarks/<recipe>/<run-id>/
├── benchmark.json
├── benchmark.md
├── environment.json
└── methodology.md
```

The `run-id` should use `YYYY-MM-DD-short-description`, for example `2026-07-21-local-ollama`.

## Capture a run

```bash
modding benchmark trusted-document-explainer \
  --models llama3.2,qwen2.5:3b,mistral \
  --output evidence/benchmarks/trusted-document-explainer/2026-07-21-local-ollama
```

Then complete `environment.json` and `methodology.md`, review every response for sensitive information, and validate the package:

```bash
python scripts/validate_evidence.py \
  evidence/benchmarks/trusted-document-explainer/2026-07-21-local-ollama
```

## Publication rules

- Preserve exact model selectors and resolved model tags.
- Record the Model Modding commit SHA used for the run.
- Record the evaluation date and local runtime versions.
- Keep stock and modded responses unless they contain sensitive input.
- Redact secrets and personal data, but never alter scores or outcomes.
- Explain all redactions in `methodology.md`.
- Do not generalise deterministic pass rates into universal model-quality claims.
- Compatibility claims may be strengthened only after repeatable evidence from more than one environment or contributor.
